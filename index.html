Présélection explicable, fondée sur les compétences et validée par un recruteur.

PROTOTYPE · DONNÉES DE DÉMONSTRATION
Confidentialité : les fichiers sont analysés localement dans ce navigateur. Aucun CV n'est envoyé sur GitHub. Cette version ne conserve pas les candidatures pendant un an : le stockage sécurisé doit être ajouté séparément.

Compétences recherchées
